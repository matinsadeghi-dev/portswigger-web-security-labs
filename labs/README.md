# Lab Write-ups

This directory contains practical write-ups from authorized PortSwigger Web Security Academy exercises. Reports document the investigation, evidence, technical reasoning, lessons learned, and remediation.

## SQL injection

| Lab | Difficulty | Status | Write-up |
|---|---|---|---|
| SQL injection UNION attack, retrieving data from other tables | Practitioner | Solved | [union-retrieve-data](sql-injections/union-retrieve-data/README.md) |
| Blind SQL injection with conditional responses | Practitioner | Solved | [blind-sqli-conditional-responses](sql-injections/blind-sqli-conditional-responses/README.md) |

The blind SQL injection folder also contains the Python automation script (`intruder.py`) and redacted screenshots in its `images/` directory.

## Scope and safety

All testing described in these reports is intended for authorized training labs. Do not test systems without permission. Never commit live session cookies, tokens, assigned lab identifiers, or recovered credentials.
